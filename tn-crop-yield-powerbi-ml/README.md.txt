Tamil Nadu Crop Production and Rainfall Analysis (2024-25)

Project Overview

This project analyzes Tamil Nadu's crop production, rainfall, and crop yield using Power BI and Python.

Tools Used

- Power BI
- Python
- Pandas
- Scikit-learn
- Random Forest Machine Learning

Project Files

- "data/" – CSV datasets
- "dashboard/" – Power BI dashboard file
- "scripts/" – Python machine learning code
- "screenshots/" – Dashboard screenshots
